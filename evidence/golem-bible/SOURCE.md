# Golem bible: size only

Source: hdmurder/golem-15 (private) `character/graph.json` at commit 4c1a6e7. Only counts and a hash are published (`stats.json`): 110 nodes and 281 undirected links in the association graph. The full first-person core, the style notes and the graph stay private. `characters/golem-15/BIBLE.md` is a short public excerpt written for this repository.

The bible is written to summon the character rather than to specify it. It has a first-person core and style, the association graph, and Impro-style masks (Keith Johnstone). During generation the controller can surface graph material in a reply. In G3 this happened in only 3 of 36 fixed calls (golem-15 `gen/g3/RESULTS.md`). That was low exposure, not evidence that the graph helps.
